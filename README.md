# 📅 Calendário de Escala de Times

Um calendário web para acompanhamento da escala de trabalho dos **Times Amarelo, Azul e Verde**, permitindo visualizar rapidamente os dias de trabalho, noites e folgas de cada equipe.

## 📷 Visual

Interface limpa, moderna e responsiva, desenvolvida para funcionar em computadores, tablets e celulares.

> *(Em breve será adicionada uma imagem ou GIF do sistema em funcionamento.)*

---

## ✨ Funcionalidades

- 📅 Visualização mensal da escala.
- 🟡 Time Amarelo.
- 🔵 Time Azul.
- 🟢 Time Verde.
- 🔴 Destaque para os períodos de folga.
- 📍 Destaque automático para o dia atual.
- ⬅️➡️ Navegação entre os meses.
- 📱 Layout responsivo para dispositivos móveis.
- ⚡ Funcionamento totalmente no navegador, sem necessidade de instalação.
